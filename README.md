# QA Terminal Practice

Небольшой учебный проект для знакомства с Git и GitHub CLI.

В нём нет рабочего кода и настоящих пользовательских данных. Все адреса и учётные записи вымышлены.

## Цель проекта

На файлах этого проекта можно безопасно потренироваться:

- клонировать репозиторий;
- создавать отдельную ветку;
- просматривать изменения;
- подготавливать файл к коммиту;
- создавать и отправлять коммиты;
- открывать Pull Request.

## Состав проекта

- `README.md` — описание проекта;
- `TASK.md` — учебное задание;
- `docs/smoke-checklist.md` — пример чек-листа тестировщика;
- `data/test-users.csv` — вымышленные тестовые данные;
- `.gitignore` — список файлов, которые не нужно добавлять в историю.

## Учебный стенд

- Адрес: `https://shop.example.test`
- Назначение: тренировка проверок главной страницы
- Данные: только вымышленные, из папки `data`

## Правила работы

1. Выполняйте задание в отдельной ветке.
2. Перед коммитом проверяйте `git status` и `git diff --staged`.
3. Не добавляйте пароли, токены и другие секреты.
4. Используйте короткие и понятные сообщения коммитов.
