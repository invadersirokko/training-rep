# Учебное задание

Добавьте в `README.md` новый раздел `Моя шпаргалка`.

В разделе должны быть пять команд из курса и краткое объяснение каждой команды своими словами.

Пример оформления одной строки:

```text
git status — показывает текущую ветку и состояние файлов.
```

## Требования

- работа выполняется в ветке `docs/terminal-practice`;
- изменяется только файл `README.md`;
- в коммит не должны попасть временные файлы и секреты;
- сообщение коммита должно объяснять изменение;
- после публикации ветки нужно открыть Pull Request в `main`.

Полная последовательность действий находятся в лабораторной работе курса.
